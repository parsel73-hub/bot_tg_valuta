# Кошелёк путешественника

Telegram-бот для учёта денежных расходов в путешествиях. Бот помогает:

- создавать путешествия между странами;
- автоматически определять валюты по названию страны;
- получать актуальный курс через API exchangerate.host;
- вести домашний и локальный баланс в поездке;
- фиксировать расходы и смотреть историю операций.

## Что умеет бот

- `/start` — приветствие и список команд
- `/new <страна дома> <страна назначения>` — создать новое путешествие
- `/balance` — показать текущие балансы
- `/topup <сумма>` — пополнить домашний баланс
- `/spend <сумма>` — зафиксировать расход в валюте назначения
- `/expenses` — показать последние расходы
- `/trips` — список путешествий
- `/use <id>` — сделать путешествие активным
- `/rate` — обновить и показать текущий курс
- `/help` — подсказка по работе с ботом

## Технологии

- Python 3
- pyTelegramBotAPI
- requests
- python-dotenv
- pycountry
- SQLite

## Установка

1. Склонируйте проект.
2. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example` и заполните значения:

```env
EXCHANGERATE_API_KEY=your_exchange_rate_api_key
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
```

## Запуск

```bash
python wallet.py
```

После запуска бот начнёт polling и будет готов принимать сообщения в Telegram.

## Структура проекта

- `wallet.py` — основной бот и обработчики команд
- `exchange.py` — работа с API курсов валют, кэш и обработка rate-limit
- `storage.py` — работа с SQLite и данными путешествий
- `countries.py` — сопоставление стран и валют
- `current_api.py` — вспомогательная проверка доступа к API
- `requirements.txt` — зависимости проекта
- `.env.example` — шаблон переменных окружения

## Примечания

- Для получения курса используется сервис `api.exchangerate.host`.
- В `exchange.py` предусмотрена защита от HTTP 429 (rate limit): повтор по `Retry-After` и ограничение частоты запросов.
- База данных создаётся автоматически при запуске бота.
